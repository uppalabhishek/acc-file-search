# ACC File Search

Demo of a file search tool for ACC projects, running on sample data.

- Search projects by site code (try `LON-001`, `MAN-014`, `BHX-207`)
- Filter, sort and select files from each project's **Project Files** folder
- **Push to ACC** tab: choose a target project, folder and optional new subfolder, then push the selected files

This is a static demonstration build. All projects, files and users are sample data and no live connection is made.

Open `index.html` in a browser to try it.
